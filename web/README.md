# web

The React 19 + Vite + Mantine frontend for the Firebase seed (Auth + Firestore).

- **Setup, scripts, env vars, project layout** → see the [root README](../README.md).
- **Adding a Firestore collection (table) or fields** → see
  [`docs/adding-a-collection.md`](docs/adding-a-collection.md), or run the **`/new-collection`**
  skill to scaffold one end-to-end.

## Quick start

```sh
npm install
npm run dev   # boots the emulators, seeds fresh data, starts Vite on :4000
```
